# PhysioMetrics Lab

A small browser-based tool for loading and exploring `.anz` physiological data files.

## Prerequisites

- [Bun](https://bun.sh/) 1.4+
- [Git](https://git-scm.com/)

## Run locally

```sh
bun install
bun run dev
```

Build the production files with:

```sh
bun run build
```
