Basic functions:

  1. Load an ".anz" file with the LOAD FILE button
  2. Change the view with the scroll bar at the top (resize either end, drag, use the scrollwheel)
  3. Create a selection by clicking and dragging on the signal plot
  4. Remove unnecessary points by clicking on them
  5. Add points by clicking anywhere in the selection
  6. To clear the selection click the CLEAR SELECTION button (or press ESC)
  7. See the statistics update in real time (bottom of the screen)
  8. Copy the current statistics to the clipboard by clicking the COPY TABLE button
  9. Save the currently visible plot as an image by clicking the COPY PLOT button
  10. Open any previously opened file (on this machine) by clicking the HISTORY button

Options:

  1. interpolation: number of points averaged into each plotted point (increase it to reduce noise)
  2. loc.ext radius: radius in which the local extrema are searched (increase it, if multiple nearby points are marked)

Statistics:

  1. cycles: number of point-pairs (number of points / 2)
  2. frequency: mean cycle frequency of the selected extrema, in Hz
  3. tone: mean absolute difference between consecutive selected extrema
  4. std: standard deviation of the selected extrema
  5. mean: mean of the selected extrema
  6. range: difference between the maximum and minimum selected extrema
